# Deploy-Checkliste

- [ ] ZIP entpacken
- [ ] Inhalt von `searchmaschinen-lernkurs` in ein GitHub-Repository hochladen
- [ ] Repository mit Netlify verbinden
- [ ] `TEACHER_CODE` in Netlify als Environment Variable setzen
- [ ] neuen Deploy auslösen
- [ ] Gastmodus testen
- [ ] Schülerkonto mit Testklasse anlegen
- [ ] Lehrerkonto mit derselben Testklasse und `TEACHER_CODE` anlegen
- [ ] Lehrerbereich und Fortschrittsanzeige testen
- [ ] Passwort-Reset, Fortschritt-Reset und Nutzerlöschung mit Testkonto testen
- [ ] Testkonto bei Bedarf wieder löschen
